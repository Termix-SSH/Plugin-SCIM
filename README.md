## Overview

SCIM Provisioning lets an identity provider like Entra ID, Okta, JumpCloud, OneLogin or Authentik manage Termix accounts. People get an account when they are assigned to Termix, their name and email stay in step, and their account is turned off when they leave. Groups can give Termix roles.

Read the [docs](https://docs.termix.site/plugins/scim) to set it up and use it.

<br />

## Features

- SCIM 2.0 server for Entra ID, Okta, JumpCloud, OneLogin, Authentik and others
- Create, update, turn off and remove accounts from your identity provider
- Map pushed groups to Termix roles
- New accounts link to their SSO or LDAP sign in by email
- More than one identity provider, each with its own URL and token
- Recent changes log per connection

## Support

Bugs and ideas for SCIM Provisioning go in this repo: [report a bug](https://github.com/Termix-SSH/Plugin-SCIM/issues/new?template=bug_report.yml) or [request a feature](https://github.com/Termix-SSH/Plugin-SCIM/issues/new?template=feature_request.yml). Report an issue on the plugin's page in the Plugins tab fills in your versions for you.

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.

Add as much detail as you can, in English if possible. For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
